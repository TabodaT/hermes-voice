# hermes-voice

Live voice client for [Hermes Agent](https://github.com/TabodaT/axi-working-brain) profiles.
A phone-installable web app that talks to any Hermes profile (coder, scout, vector, banel, …)
with real-time voice, comparable to ChatGPT's voice mode.

> **Start here: [PLAN.md](./PLAN.md)** — full design, reference code, phased build.

## Status

Planning / pre-implementation. v0.1 will be an Android-Chrome PWA that streams
speech to a Hermes API server over SSE and plays per-sentence TTS, with real
barge-in. Optional WebSocket upgrade in v0.2.
